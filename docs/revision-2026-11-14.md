# Revisi pilot 14 November 2026

Implementasi diperiksa melalui pembacaan source saja. Aplikasi, server, build, lint, typecheck, unit/integration/browser test, webcam, dan simulasi tidak dijalankan. Tidak ada data TEST baru, commit atau push. Hasil tes 13 November bukan bukti validasi versi ini.

## Alur dan state machine

Sesi baru memakai `config.interactionPolicy=USER_APPROVED_V1`. DEFAULT → dua window negatif valid → tawaran modal. Mode masih DEFAULT sampai peserta memilih FOCUS atau ASSISTED. Pilihan TIDAK mempertahankan DEFAULT. Escape, backdrop, atau X dicatat sebagai CLOSED; tidak dijawab sampai timeout dicatat IGNORED. Tawaran tidak dibuka di NON_ADAPTIVE, saat adaptasi dinonaktifkan, atau saat mode pilihan sudah aktif. Kontrol manual mengizinkan DEFAULT/FOCUS/ASSISTED tanpa trigger baru dan tetap mencatat alasan/transisi.

Cooldown setelah pilihan 30 detik. Penolakan/penutupan/timeout memakai `offerSuppressionMs` (sementara 30 detik). Timeout `offerTimeoutMs` sementara 30 detik. Keduanya ada di `USER_APPROVED_CONFIG`, dibekukan pada sesi, dan perlu ditinjau bersama pembimbing. Timer sesi berhenti serta tawaran ditandai diabaikan ketika input terputus/tab disembunyikan/halaman ditinggalkan. Tidak ada suara atau animasi tambahan.

Recovery: dua window stable valid setelah cooldown dan delay 1 detik memulihkan hitungan sinyal. Mode yang dipilih pengguna tidak otomatis dibatalkan. Dialog yang sedang dipertimbangkan tetap menunggu jawaban atau timeout aslinya. Negatif/UNKNOWN baru membatalkan recovery sinyal yang belum selesai. Kembali ke DEFAULT dilakukan pengguna. Keputusan ini menghindari pembatalan pilihan secara mendadak; konfirmasikan dalam protokol final. Snapshot lama tanpa policy mempertahankan engine bertahap lama dan diberi pemberitahuan pada halaman belajar. Gunakan sesi baru untuk revisi ini.

## Pemeriksaan manual oleh peneliti

1. Buat sesi TEST baru dengan kode belum terpakai dan PILOT_C, urutan 1/3. Pastikan panduan muncul dan kode peserta sesuai record.
2. Periksa 8 soal dan opsi A–E pada keempat paket; jawaban kosong harus memblokir kirim. Tinjau kualitas distractor, kunci dan cakupan dengan pembimbing.
3. Pastikan kamera hanya pada LEARNING, termasuk NON_ADAPTIVE; cabut izin/ubah posisi/sembunyikan tab dan periksa status/label stale.
4. Pada ADAPTIVE, trigger harus membuka modal tanpa mengubah mode. Coba FOCUS langsung, ASSISTED langsung, TIDAK, Escape/X/backdrop, timeout, dan tab tersembunyi. Periksa suppression dan log setiap kasus.
5. Dari kedua mode coba tombol kembali normal dan pindah mode manual. Stable recovery tidak boleh membatalkan pilihan. Periksa posisi baca, navigasi keyboard, fokus setelah modal dan layar kecil.
6. Periksa tooltip dengan mouse/touch/keyboard, visual seluruh subbab, serta akses bantuan yang sama pada NON_ADAPTIVE.
7. Isi CLT bertahap, kembali ke bagian sebelumnya, refresh dan lanjutkan. Semua jawaban harus tersimpan; pengiriman final hanya sekali dan skor tidak ditampilkan.
8. Selesaikan kedua blok, buka bahan bilingual khusus pilot, cocokkan teks dengan Table 11 dan catat feedback di lembar terpisah.
9. Bandingkan dashboard dengan ekspor JSON/ITEMS/TESTS/MINUTES/AUI-EVENTS. Periksa jumlah pilihan dan durasi mode; uji retry tanpa duplikasi menggunakan data uji milik peneliti.

Durasi maksimum 60 menit masih kandidat lama; 32 soal, dua CLT dan peninjauan bilingual dapat melampauinya. Tidak ada penghentian/pengisian otomatis. Tetapkan alokasi final setelah pilot dan keputusan pembimbing.
