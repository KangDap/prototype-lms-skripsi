# Kisi-kisi tes pilot

Semua soal draf berbobot satu, 8 per tes, 5 opsi A–E. Indeks jawaban internal/ekspor 0–4. Review pakar dan pilot masih diperlukan untuk memastikan satu jawaban terbaik, kualitas distractor dan kesetaraan kesulitan.

| Konsep | Sampling Bias pretest | Sampling Bias posttest |
|---|---|---|
| Populasi dan sampel | PRE-1 | POST-1 |
| Jangkauan/undercoverage | PRE-2 | POST-2 |
| Voluntary response | PRE-3 | POST-3 |
| Inferensi dan perbaikan | PRE-4 | POST-4 |
| Kerangka sampel | PRE-5 | POST-5 |
| Representativitas relevan | PRE-6 | POST-6 |
| Convenience sampling | PRE-7 | POST-7 |
| Nonresponse | PRE-8 | POST-8 |

Kedua bentuk memakai kasus berbeda dan cakupan konsep sebanding. Kesetaraan kesulitan empiris serta kualitas pilihan jawaban perlu ditinjau sebelum MAIN.

| Konsep | Correlation vs Causation pretest | Posttest |
|---|---|---|
| Arah hubungan | PRE-1 | POST-1 |
| Batas klaim kausal | PRE-2 | POST-2 |
| Confounding | PRE-3 | POST-3 |
| Penugasan acak | PRE-4 | POST-4 |
| Pasangan data scatter plot | PRE-5 | POST-5 |
| Kekuatan pola linear | PRE-6 | POST-6 |
| Hubungan nonlinear | PRE-7 | POST-7 |
| Penjelasan arah terbalik | PRE-8 | POST-8 |

Pretest digunakan sebagai indikator pengetahuan awal; skor posttest/gain merupakan hasil pendukung. Jangan memberi feedback kunci atau pembahasan selama eksperimen. Materi dan tes sama untuk kondisi Adaptive dan Non-Adaptive.
